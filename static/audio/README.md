# Audio assets for AI Album viewer

Place the following files here:

- **page-flip.mp3** – Short paper flip SFX (played on goNext/goPrev).
- **default_bgm.mp3** – Default BGM when no emotion match.
- **joy_bgm.mp3** – Excited / Joy / Energetic.
- **peaceful_bgm.mp3** – Peaceful / Romantic / Calm.
- **sad_bgm.mp3** – Sad / Nostalgic.

If a file is missing, the app falls back to `default_bgm.mp3` or skips playback.
